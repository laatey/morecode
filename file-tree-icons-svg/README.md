# File tree SVG icons

Hand-drawn, standalone SVGs based on the file icon styles in the supplied screenshots. These are original approximations made for this project, not extracted assets from ChatGPT.

Each icon uses a 24 × 24 viewBox and can be used as an `<img>` source or inline SVG. The colored language tiles include their label as vector text.

## Included

`archive`, `css`, `docker`, `electron`, `eslint`, `file`, `folder`, `git`, `image`, `javascript`, `json`, `markdown`, `prettier`, `python`, `react`, and `typescript`.
